# tauri-plugin-donizetti

Donizetti's Tauri 2 plugin: what `<ScoreEditor>` needs from the native side.
Scores read and written (with a hash guard), the MuseScore General soundfont
downloaded, read and removed ([donizetti_soundfonts](../soundfonts/README.md)),
and PDF export ([donizetti_pdf](../pdf/README.md)). Its typed client is
`@donizetti/tauri` (`packages/tauri`).

```rust
tauri::Builder::default()
    .plugin(tauri_plugin_donizetti::init())
    // or, with the soundfont somewhere other than app_data_dir()/soundfonts:
    // .plugin(tauri_plugin_donizetti::Builder::new().soundfont_dir(folder).build())
```

and `"donizetti:default"` in the window's capability. The commands, their
arguments, answers and error codes are in
[the Tauri integration](../../docs/features/tauri.md).

The commands are thin: each passes its arguments to a function of the crate
(`read_score`, `write_score`, `export_pdf`, `Soundfonts`), on a blocking
thread. `build.rs` lists the commands; Tauri writes their permissions to
`permissions/autogenerated` and `permissions/default.toml` allows them all.
Tests are in `tests/unit` and use Tauri's mock runtime.
